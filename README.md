# LCS - Released Content

Released educational content for **Learn C++ School** (LCS).

This repository contains content packages that can be downloaded and used by compatible LCS applications.

## About

The LCS application and its educational content are maintained separately.

The application itself is open source, while the educational content is proprietary. This repository contains only content intended for distribution.

```text
Learn C++ School
├── core
│   └── Open-source application core
│
├── console
│   └── Open-source console application
│
└── content-release
    └── Released content
```

## Content

Released content may be organized into different editions and versions as the project evolves.
The exact availability of content depends on the version of Learn C++ School being used.

## Integrity

Released content is cryptographically signed so that compatible LCS applications can verify that it was published by **Learn C++ School** and has not been modified.
